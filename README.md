# iiode website

Marketing website for iiode and the Re27 lighting system. The application is a
Next.js App Router project with localized content, HubSpot forms, consent-gated
analytics, and a server-generated press-preview download.

## Stack

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4, loaded from `src/app/globals.css`
- HubSpot embedded forms and tracking
- JSZip for the protected press-preview archive
- pnpm
- Node.js 24

## Local setup

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

The required Node version is recorded in `.nvmrc` and enforced by
`package.json`. Copy `.env.example` to `.env.local` only when overriding an
environment value.

## Commands

```bash
pnpm dev           # development server
pnpm lint          # ESLint
pnpm build         # optimize active SVG assets, then create a production build
pnpm start         # start the production server
pnpm svg:optimize  # run SVGO on public/assets/Re27/exploded
```

The pre-commit hook optimizes staged SVG files in the exploded-view directory.

## Routes

- `/` - Re27 landing page
- `/collaborations` - collaboration overview and image carousel
- `/about` - company and contact information
- `/downloads` - HubSpot-gated press-preview download
- `/preorder` - local pre-order product and price selection flow
- `/terms-and-services` - text-heavy terms and services page
- `/api/downloads/press-preview` - creates the press ZIP in memory
- `/api/locale` - persists the selected locale
- `/api/theme` - persists the selected theme

`robots.txt` and `sitemap.xml` are generated by Next.js route metadata.

## Content and localization

User-facing copy lives in:

- `src/content/locales/en.ts`
- `src/content/locales/fr.ts`
- `src/content/locales/de.ts`

All locales implement the shared contract in
`src/content/locales/types.ts`. Shared asset paths are centralized in
`src/content/locales/assets.ts`.

The locale switch writes an `iiode-locale` cookie. The default locale is
English. Theme selection uses the `iiode-theme` cookie and defaults to dark.

## Styling

Tailwind CSS is active and required. It is imported with:

```css
@import "tailwindcss";
```

Components use Tailwind utilities for layout and state styling. Site-specific
tokens and reusable `iiode-*` classes live in `src/app/globals.css`.

The site currently loads Selecta Medium from its WOFF2 and WOFF files. The
complete Selecta family is intentionally retained in
`public/assets/fonts/Selecta` for future typography work.

## HubSpot

HubSpot configuration is centralized in `src/content/hubspot.ts`. It contains:

- portal and region
- the embed script URL
- form IDs for newsletter and press preview

The global HubSpot tracking script is intentionally not loaded. That prevents
HubSpot-hosted pop-up forms from appearing on page load or navigation.

The embed script is loaded by `HubspotFormEmbed` only when a user opens an
explicit form trigger. Form submission handling and download redirects are
managed by `HubspotFormModalTrigger`.

When changing a form in HubSpot, update its ID in `src/content/hubspot.ts` and
test both successful submission and the email fallback.

## Analytics and consent

Google Analytics uses `NEXT_PUBLIC_GA_MEASUREMENT_ID` when present, otherwise
it falls back to the ID in `src/content/site.ts`.

```bash
NEXT_PUBLIC_GA_MEASUREMENT_ID=
```

`CookieConsent` gates Google Analytics. The HubSpot form embed remains available
without analytics consent because it loads only after an explicit form action.

## Assets

Only files below `public/` are served at runtime. Important groups:

- `public/assets/Re27/exploded` - active animated SVG and static posters
- `public/assets/collaborations` - collaboration page images
- `public/assets/mood` - section photography
- `public/assets/press` - files included in the generated press ZIP
- `public/assets/fonts/Selecta` - complete font family; Medium is currently loaded

The exploded SVG is fetched and injected client-side so its SMIL timeline and
stroke color can be controlled by `AnimatedExplodedSvg`.

## Production

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

The start wrapper respects `HOST`, `HOSTNAME`, and `PORT`, with
`0.0.0.0:3000` as the fallback.

Before deployment, run:

```bash
pnpm lint
pnpm build
```
